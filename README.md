# Glizzy Landingpage

Statische Landingpage für `glizzybot.app` (HTML, CSS und JavaScript ohne Build-Schritt).

## Vor dem Livegang

1. In [`config.js`](./config.js) `YOUR_DISCORD_CLIENT_ID`, `YOUR_SUPPORT_INVITE` und den Ryzehosting-Affiliate-Link ersetzen.
2. Die Platzhalterangaben in [`impressum.html`](./impressum.html) und [`datenschutz.html`](./datenschutz.html) vervollständigen.
3. `assets/glizzy-avatar.gif` aus dem bestehenden Glizzy-Projekt bereitstellen.
4. Die Domain auf das Verzeichnis zeigen lassen. Es werden keine `.env`-Dateien oder Backend-Daten benötigt.

## Lokal testen

Zum lokalen Testen reicht ein statischer Server, zum Beispiel `npx serve .` im Landingpage-Verzeichnis.
